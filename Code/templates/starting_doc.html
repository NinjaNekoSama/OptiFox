API User Manual

Running the Flask App and Accessing Swagger UI

This repository contains a Flask application that provides APIs for accessing patient time series data. Follow the instructions below to run the application locally and interact with the APIs using Swagger UI.

OpenAPI 3.0.0 Format

The API documentation follows the OpenAPI 3.0.0 specification, providing a structured description of endpoints, parameters, and responses.

Interactive Documentation

Use Swagger UI to test various endpoints by providing required parameters and executing requests directly from the interface.

Prerequisites

  1. Python 3.10 or above
  2. Open the codebase in a dev container and build it using the provided config. This should be fairly simple in VS Code. You can also find further information on dev containers in the Dev Containers Tutorial.
  3. If you are somehow unable to accomplish the second prerequisite, the APIs should also work in a virtual environment after installing all the requirements listed in the project requirements.txt.

After running the application in a dev container, run server.py to launch the Flask server, then navigate to the URLs below depending on your interests:

API Documentation

You can access the main Flask API documentation at the following URL. This is not only a place where you are provided documentation on each API but also a playground to try out these APIs:

Versioning

  • /api/v1 does not require JWT tokens or any kind of authentication.
  • /api/v2 is the latest API version which does need a token to access the APIs.

Without authentication

http://localhost:3000/api/v1/ui/

With authentication

http://localhost:3000/api/v2/ui/

Measure the Performance 🚀

Although not sophisticated, we also provide Prometheus metrics, which can help understand the performance of the APIs. This requires more work, but this basic setup lays the groundwork to further optimize the performance in the future:

http://localhost:3000/metrics

Usage

Authorization

  1. First, you have to log in with the username "nani" and password "optifox" to generate the JWT token.
  2. After you generate the JWT token, from the response, you need to log in with the said token to be able to use the APIs.

Note: If you are using these APIs for your frontend, make sure to send the token as part of the request header!

Endpoints

The Swagger UI will list all available endpoints along with their descriptions and input parameters.

Testing

Use the Swagger UI to test various endpoints by providing required parameters and executing requests directly from the interface.

Logging

There is also a logging capability where all the logs are written to a log folder, which is autogenerated. This should give you further insights into the inner workings of the Flask APIs.
